### 📌 Featured Project

#### 🎯 AVSMS — AI-Assisted Violence & Attendance Monitoring System
> A full-stack school monitoring platform with role-based dashboards, RFID attendance, real-time AI-assisted threat detection, and SMS alert workflows.

**Stack:** Laravel 12 · React 19 · TypeScript · Inertia.js · MySQL · Redis · Tailwind CSS · Roboflow · Google Gemini · FFmpeg · Nginx

**Highlights**
- 🔐 Role-based access control (admin, staff, parent)
- 📡 Real-time alert pipeline via queue workers
- 🤖 AI-assisted detection with secondary verification flow
- 📹 Live camera ingestion (RTSP/HLS/WebRTC) + clip extraction
- 🪪 RFID-driven attendance logging
- 🚀 Production deployment on Linux with Nginx + Supervisor + systemd
