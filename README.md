## About

I'm a full-stack developer building **secure monitoring, attendance, and dashboard systems** with the **Laravel + Inertia + React** stack. Currently focused on shipping **AVSMS** — an AI-assisted school safety platform combining real-time camera analytics, RFID attendance, and queue-driven alert pipelines.

- 🛠 &nbsp;Currently building &nbsp;·&nbsp; **AVSMS** (Laravel 12 · React 19 · TypeScript · Roboflow · Gemini)
- 🎯 &nbsp;Focused on &nbsp;·&nbsp; clean architecture, RBAC, async pipelines, and production deployment
- 🌱 &nbsp;Exploring &nbsp;·&nbsp; advanced TypeScript, system design, and Linux DevOps
- 📬 &nbsp;Reach me at &nbsp;·&nbsp; [jaelanzano18@gmail.com](mailto:jaelanzano18@gmail.com)
